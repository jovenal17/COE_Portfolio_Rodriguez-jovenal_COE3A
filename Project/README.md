# 📌 Project 1: Simple Calculator (C++)

## 📖 Project Overview
This is a basic calculator program written in C++. It performs four main mathematical operations: addition, subtraction, multiplication, and division. This project demonstrates my understanding of core programming concepts such as variables, user input, decision structures, and error handling — essential skills for Computer Engineering.

## 🛠️ Tools & Technologies
- *Language:* C++
- *Editor:* Visual Studio Code
- *Compiler:* GCC / MinGW

## ✨ Features
- Accepts two integer numbers from the user
- Supports: + Addition, - Subtraction, * Multiplication, / Division
- Includes error check: cannot divide by zero
- Simple, clean, and easy-to-read interface

## 📚 What I Learned
- How to read input and show output in C++
- How to use switch-case for multiple choices
- How to handle basic errors in programs
- How to write structured and readable code

## 📝 How to Run
1. Compile: g++ main.cpp -o calculator
2. Run: ./calculator
3. Enter numbers and operator when prompted
