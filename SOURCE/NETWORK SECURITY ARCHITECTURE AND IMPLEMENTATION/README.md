 Network Security Architecture and Implementation Report
*• Type:* Network Security / System Administration Project
*• Organization:* ALCRC Corp.
*• Description:*
Design, hardening, and monitoring of a secure virtualized network infrastructure. Covers network topology, IP addressing, firewall rules, access control, traffic monitoring, intrusion detection, and threat response protocols. Built using OPNsense, Suricata IDS, Ubuntu Server, and analysis tools (Nmap, Wireshark).
*• Technologies Used:* OPNsense, Suricata, Ubuntu Server, XAMPP, Nmap, Wireshark, Virtualization
