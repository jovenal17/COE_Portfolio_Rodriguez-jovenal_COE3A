Project 3: Cantilever 3D Printer Design
*Type:* Design / Fabrication / Mechanical Project
*Course & Section:* Computer Engineering – COE3A

## 📖 Description
CAD design and concept development of a *Cantilever-style 3D Printer*. Features a single vertical support column, making it simple, compact, and cost-effective. Covers mechanical structure, motion system, and component layout.

## 🛠️ Technologies Used
- CAD Software: Fusion 360 / SolidWorks
- Concepts: Mechanical Design, Rapid Prototyping, Mechatronics

## ✨ Features
- Simple cantilever frame structure
- Standard motion system (XYZ axes)
- Open design for maintenance
- Educational purpose design

## 📚 Learning Outcome
- 3D modeling and CAD skills
- Mechanical structure design
- Integration of electronics and mechanics
- Understanding of additive manufacturing
