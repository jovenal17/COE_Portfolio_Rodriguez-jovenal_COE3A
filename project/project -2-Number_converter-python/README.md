# 📌 Project 2: Number Converter (Python)

## 📖 Project Overview
This program converts a Decimal number into its Binary and Hexadecimal equivalents. Understanding number systems is a fundamental topic in Computer Engineering, used in digital electronics, computer architecture, and low-level programming. This project shows my ability to apply programming logic to engineering concepts.

## 🛠️ Tools & Technologies
- *Language:* Python
- *Editor:* Visual Studio Code
- *Concepts:* Number systems, type conversion, string manipulation

## ✨ Features
- Takes any decimal number as input
- Converts to Binary format
- Converts to Hexadecimal format
- Clean and clear output

## 📚 What I Learned
- How to use Python built-in functions: bin() and hex()
- How to format output by removing prefixes
- Understanding relationship between decimal, binary, and hexadecimal
- Applying programming to engineering basics

## 📝 How to Run
1. Open terminal
2. Run: python number_converter.py
3. Enter any number
